# Style Bible — پرونده «دزد کتابخانه»

## هویت کلی

بازی یک ماجرای کارآگاهی آموزشی برای کودکان ۷ تا ۱۴ سال است.

فضای بصری باید حس:

**کنجکاوی + کشف + هوشمندی + ماجراجویی**

را منتقل کند.

دنیا کاملاً **معاصر و امروزی** است و در یک شهر مدرن ایران اتفاق می‌افتد.

هیچ‌کدام از محیط‌های اصلی نباید ظاهر تاریخی، سنتی یا توریستی داشته باشند.

فضا نباید:

* ترسناک
* تاریک
* جنایی بزرگسالانه
* کودکانه‌ی خردسال
* بیش از حد کارتونی
* سنتی یا تاریخی

باشد.

---

# سبک هنری

## سبک اصلی

**Modern 2D Illustrated Mobile Game Art**

با ویژگی‌های:

* Semi-cartoon
* تمیز و مدرن
* طراحی مینیمال کنترل‌شده
* جزئیات متوسط
* خوانایی بالا روی موبایل
* فرم‌های هندسی ساده
* نورپردازی نرم و طبیعی
* سایه‌های سبک
* طراحی محیط شبیه فضاهای عمومی امروزی

ظاهر بازی باید شبیه یک **بازی موبایل داستانی مدرن و حرفه‌ای** باشد.

نه تصویر کتاب کودک.

نه نقاشی واقع‌گرایانه.

نه فضای سنتی ایرانی.

---

# مخاطب

سن هدف:

**7–14**

طراحی باید:

* برای کودک ۷ ساله واضح باشد
* برای نوجوان ۱۳–۱۴ ساله بچه‌گانه به نظر نرسد

کاراکترها کمی stylized باشند، اما:

* بدون سرهای بزرگ
* بدون فرم chibi
* بدون اغراق کارتونی زیاد

# هویت ایران مدرن

محیط باید به شکل طبیعی حس کند که در ایران امروز قرار دارد، اما این هویت نباید از طریق معماری سنتی منتقل شود.

هویت ایرانی بیشتر از طریق جزئیات روزمره منتقل شود:

* کتاب‌های فارسی
* تابلوهای فارسی
* نام بخش‌ها به فارسی
* لباس‌های امروزی ایرانی
* طراحی واقعی فضاهای عمومی شهری ایران
* مبلمان و تجهیزات معاصر
* نشانه‌های کوچک فرهنگی روزمره

نباید از موارد زیر به‌عنوان هویت اصلی ایران استفاده شود:

* طاق‌های سنتی
* کاشی‌کاری تاریخی
* فرش سنتی به‌عنوان عنصر اصلی
* گنبد
* پنجره‌های سنتی
* مقرنس
* معماری بازار یا خانه تاریخی
* تزئینات صفوی یا قاجاری
* رنگ‌بندی توریستی ایران

هدف:

**Modern Iran, not traditional Iran.**

# فضای کتابخانه

کتابخانه یک **کتابخانه عمومی مدرن شهری در ایران** است.

فضا باید شبیه کتابخانه‌ای باشد که در دهه ۲۰۲۰ یا ۲۰۳۰ ساخته یا بازسازی شده است.

ویژگی‌ها:

* قفسه‌های مدرن چوب و فلز
* میزهای ساده و مینیمال
* صندلی‌های امروزی
* نور خطی سقفی یا pendant lights ساده
* شیشه و فلز در بعضی بخش‌ها
* کفپوش مدرن
* کامپیوترهای کتابخانه
* تابلوهای راهنما
* بخش مطالعه باز
* میز اطلاعات مدرن
* کمدهای مراجعه‌کنندگان
* نمایشگاه کوچک کتاب‌های ارزشمند

فضا باید:

* روشن
* مرتب
* آرام
* قابل اعتماد
* معاصر

باشد.

# نورپردازی

نور اصلی:

**Bright modern indoor daylight**

ترکیب:

* نور طبیعی پنجره‌ها
* چراغ‌های سقفی مدرن
* نور نرم و یکنواخت

صحنه‌ها نباید dramatic باشند.

حتی انبار:

# دوربین

تمام صحنه‌ها باید زبان تصویری مشابه داشته باشند.

زاویه پیشنهادی:

**Slightly elevated three-quarter view**

یا:

**Natural eye-level with mild perspective**

هدف:

* محیط واضح باشد
* اشیای تعاملی دیده شوند
* حس بازی موبایل حفظ شود

از زاویه‌های:

* خیلی سینمایی
* خیلی پایین
* خیلی بالا
* fisheye
* perspective اغراق‌شده

استفاده نشود.

# طراحی کتاب سرقت‌شده

کتاب تنها عنصر تاریخی مهم پرونده است.

این تضاد عمدی است:

**محیط مدرن + کتاب قدیمی**

ویژگی کتاب:

* جلد سبز تیره
* لبه‌های کمی فرسوده
* حاشیه محدود طلایی
* ظاهر قدیمی و ارزشمند
* اندازه کمی بزرگ‌تر از کتاب معمولی

کتاب باید واضحاً متعلق به گذشته باشد، اما محیط اطرافش کاملاً امروزی بماند.
